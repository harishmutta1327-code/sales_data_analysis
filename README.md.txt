# Sales Data Analysis using Python

## Project Overview

This project analyzes sales data using Python and Pandas to identify sales trends, top-performing products, categories, cities, and monthly revenue patterns.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Excel
- Jupyter Notebook

## Dataset

The dataset contains 500 sales records with information such as:

- Order ID
- Order Date
- Product
- Category
- City
- Quantity
- Unit Price
- Total Sales

## Analysis Performed

- Dataset exploration
- Missing value analysis
- Duplicate record detection and removal
- Total revenue calculation
- Total order calculation
- Top-selling product analysis
- Category-wise sales analysis
- City-wise sales analysis
- Monthly sales analysis

## Visualizations

The project includes the following charts:

- Monthly Sales
- Category-wise Sales
- City-wise Sales
- Top-selling Products

## Business Insights

The analysis identifies:

- Total revenue generated
- Top-selling product
- Highest revenue category
- Top-performing city
- Best-performing month
